The big picture

We run one repeatable pipeline for every ICP × country combination. Contacts are sourced and qualified in Apollo, routed and stored in HubSpot, then emailed from Lemlist. The goal is that once a combination is set up, it stays fresh on its own — new matching contacts flow in automatically, and outdated ones drop out.

Our ICPs

An ICP (Ideal Customer Profile) is a defined type of firm/person we target. Each ICP has its own Apollo persona, its own AI qualification filter, its own HubSpot list, and its own Lemlist email copy — they are never mixed. Click one to see how we define it.

Apollo — source & qualify contacts
Apollo is where leads enter the pipeline. You define who we want (persona filters), add them to a dedicated ICP × country list, and set up a workflow so the list maintains itself. Contacts are AI-qualified and stamped with an ICP before they ever reach HubSpot.
1
Apollo · Step 1
Select the persona filters for this ICP + country
Done ▶
What & why

Open the persona that belongs to this exact ICP (e.g. Private Equity) and confirm its filters are active. The persona is what defines "who counts" — management level, title keywords, exclusions and company size. Then layer on the target country and require a verified email.

Each ICP has its own persona — never reuse another ICP's persona, or you'll pull the wrong people.

HubSpot — route & store contacts
HubSpot is the CRM of record. You build one dynamic list per ICP × country with the right filters, then push qualified contacts from Apollo. Because the lists are dynamic, matching contacts route themselves into the correct list with no manual sorting.
4
HubSpot · Step 4
Create the ICP + country list with filters
Done ▶
What & why

Create an active (dynamic) list for the ICP + country. The fastest route is to duplicate an existing ICP list that already has the correct ICP filters, then change only the country condition. Dynamic means the list re-evaluates itself — contacts are picked up or dropped as their properties change.

Watch
Key facts
ImportantThe list must be Active / dynamic, never Static. A static list won't pick up newly pushed contacts.
TipWhen duplicating an ICP list, change only the country filter — leave the ICP filters as they are.
ICP = [ICP] (already set) Update: Country = [target] Active / dynamic

Lemlist — email & launch
Lemlist is where contacts actually get emailed. Each ICP has its own campaign with copy written for that audience. You import the matching HubSpot list, map the fields, choose sending accounts, and launch according to the sending criteria.

Done ▶

Create a new campaign for this ICP and build the email sequence using the copy written for that audience (subject lines, steps, delays). Each ICP speaks to a different reader, so the copy is never shared across ICPs.

Frequently asked
GeneralDo I run one pipeline for everything, or one per ICP and country?▶
One full pipeline per ICP × country combination. Each has its own Apollo list + workflow, its own HubSpot dynamic list, and its own Lemlist campaign. They are never merged — this keeps qualification, copy and sending volumes clean.
ApolloWhy can't I just duplicate an existing list to make a new one?▶
Duplicating a list in Apollo also copies all of its current contacts, which creates deduplication problems downstream. Always create a fresh, empty list and let the workflow populate it.
ApolloMy AI filter / workflow stopped adding contacts. Why?▶
Most often it's the Apollo plan limit. Bulk AI research and auto-add are capped by plan (Basic ≈ 100/day). Check remaining credits/limits, or run in batches of 100.
HubSpotA contact isn't showing up in the list I expected.▶
Check two things: (1) the list is Active / dynamic, not Static; (2) the contact's ICP and Country properties actually match the list filters. Those properties flow from Apollo, so fix them upstream if they're wrong.
LemlistMy email variables (name, company) are showing up blank.▶
The field wasn't mapped on import. Re-check the field mapping step — every variable used in the copy must map to a HubSpot field, including Country.
LemlistHow do I make sure someone isn't emailed by two campaigns at once?▶
Turn on "skip contacts already in another campaign" during import. This prevents double-enrolment.
